# learning-loop 学习闭环桥接器

> **版本**: 1.0.0 | **优先级**: P4-8 (P2) | **维度**: D4-Learning | **创建**: 2026-05-12
> **触发词**: 学习闭环、模式演化、本能更新、learning loop、feedback loop

## 功能概述
桥接 SessionAnalyzer → RLOptimizer → Instinct，形成 OBSERVE→ANALYZE→LEARN→EVOLVE→APPLY 五阶段自动学习闭环。

## CLI
```bash
node learning-loop.js loop code 7 180 10 2
node learning-loop.js stats
node learning-loop.js report
```
